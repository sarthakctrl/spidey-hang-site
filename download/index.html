Download

Put him on your desktop.

Free, for Windows, macOS and Linux. Pick your computer. The download is about 100 MB, almost all of it the Electron runtime every Electron app carries; Spidey's own part is about 1.3 MB.

Looking up the latest version…

Windows

  1. Run the downloaded Setup .exe. It installs for you only and needs no admin rights.
  2. He starts straight away and hangs from the top of your screen.
  3. His menu: right-click him, or the spider-web icon by the clock. A left-click on that icon gives him a swing.

Uninstalling also removes his start-at-sign-in entry.

macOS

  1. Open the .dmg and drag Spidey Hang into Applications.
  2. Open him from Applications. The build is not notarized, so the first time, right-click the app and choose Open (or allow it under System Settings › Privacy & Security).
  3. He has no Dock icon. Look for him at the top of the screen and for the spider-web icon in the menu bar.

Opened from anywhere else (the disk image, Downloads), he offers to move himself to Applications, so starting at login keeps working.

Linux

  1. Double-click the .deb to install it from App Center, or in a terminal: 
    sudo apt install ./spidey-hang_*_amd64.deb
  2. Start Spidey Hang from the app grid.
  3. His menu: right-click him, or the spider-web icon in Ubuntu's top bar.

Built for Ubuntu 22.04 and newer, 64-bit Intel/AMD. Linux Mint, Pop!_OS and Debian use the same file. Remove him with sudo apt remove spidey-hang.

Not starting?

I can't see him.
Spidey has no window and no Dock icon. Look at the top of the screen, and for the spider-web icon in the menu bar (Windows: by the clock).
An older copy keeps winning.
Only one Spidey runs at a time, so an older copy that is already running wins. Opening the app again while he is up just gives him a swing.
I once had the Spidey Hang VS Code extension.
It starts its own old copy whenever VS Code opens, and the app warns you about it. Uninstall it in VS Code's Extensions view, then delete ~/.spidey-hang/app and ~/.spidey-hang/runtime.
He misbehaves.
Every start, layout and problem is written to ~/.spidey-hang/log.txt (%USERPROFILE%\.spidey-hang\log.txt on Windows). Check it first.
Linux: he isn't above my windows.
Wayland (Ubuntu's default) doesn't let an app stay above other windows, so Spidey runs under X11 through XWayland, which every Wayland desktop has. Started any other way than the app grid, he restarts himself that way.
Linux: no tray icon, or a black box around him.
Other GNOME desktops (Fedora, plain Debian) only show the tray icon with the AppIndicator and KStatusNotifierItem Support extension; right-clicking Spidey opens the same menu either way. Transparency needs a compositing desktop (GNOME, KDE, Cinnamon, Xfce and MATE all are).
I don't want him at sign-in.
Untick Start automatically in his menu. On Windows that removes the entry under Task Manager › Startup apps; on macOS, the login item.

Build him yourself.

Needs Node.js 22 or newer. From a copy of the app's code:

Run it, or install it here

npm install
npm start      # run from the source folder
npm run app    # build, install and start it on this computer

Make installers to share

npm run dist:win   # on Windows: the Setup .exe
npm run dist:mac   # on a Mac: arm64 and x64 .dmg
npm run dist:linux # on Linux: the amd64 .deb

Each system's installer is built on that system. The app's GitHub workflow builds both and attaches them to a release when a version tag is pushed.
